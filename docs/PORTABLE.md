# QNote 便携版

## 📦 什么是便携版？

便携版是一个压缩包，包含了应用程序的所有必要文件。解压后无需安装即可运行，可以放在U盘或任何文件夹中直接使用。

## ✨ 便携版特点

- **无需安装**: 双击即可运行
- **绿色软件**: 不会在系统中留下注册表项
- **数据独立**: 配置和数据文件保存在程序目录下
- **便于携带**: 可以放在U盘中随身携带

## ⚠️ 便携版不支持自动更新

便携版没有安装器，无法"覆盖安装自己"——即使下载到新的安装程序，
NSIS 也只会把它装到系统程序目录，用户手里这个便携目录仍然是旧版本。

因此便携版会自动关闭「设置 → 数据与开发 → 应用更新」里的自动更新，
改为提供「打开下载页」按钮，手动下载新版本后覆盖解压即可。

（程序通过 `resources/portable.marker` 识别自己是便携版，这个文件由
`scripts/build/post-build.js` 在压缩前写入。）

## 🚀 获取便携版

### 方法一：从GitHub Releases下载（推荐）

1. 访问 [GitHub Releases页面](https://github.com/Ruciazyt/qnote-elec/releases)
2. 选择最新版本
3. 下载 `QNote-x.x.x-portable.zip` 文件
4. 解压到任意文件夹
5. 双击 `QNote.exe` 即可运行

### 方法二：本地构建

如果你想自己构建便携版：

```bash
# 先安装工作区依赖
pnpm install

# 构建便携版
pnpm run build-portable
```

构建完成后，便携版文件将位于 `dist_electron/` 目录下。

## 📁 便携版目录结构

解压便携版压缩包后的目录结构：

```
QNote-portable/
├── QNote.exe       # 主程序
├── resources/      # 应用资源
├── locales/        # 语言文件
├── data/           # 数据库文件（运行后生成）
├── config/         # 配置文件（运行后生成）
└── logs/           # 日志文件（运行后生成）
```

## 🔧 GitHub自动构建

每次发布新版本时，GitHub Actions会自动构建两个版本：

- **安装版**: `QNote-Setup-x.x.x.exe` - 传统安装程序
- **便携版**: `QNote-x.x.x-portable.zip` - 免安装压缩包

### 发布流程

开发者只需执行以下命令即可触发自动构建和发布：

```bash
# 发布补丁版本（如 1.0.0 -> 1.0.1）
pnpm run release:patch

# 发布次要版本（如 1.0.0 -> 1.1.0）
pnpm run release:minor

# 发布主要版本（如 1.0.0 -> 2.0.0）
pnpm run release:major
```

GitHub Actions工作流会自动：
1. 更新版本号并创建Git标签
2. 构建安装版和便携版
3. 创建GitHub Release
4. 上传构建文件

## 🔄 自动更新

便携版同样支持自动更新功能：

1. 打开设置页面
2. 点击"检查更新"按钮
3. 如有新版本，会提示下载和安装

## ⚠️ 注意事项

1. **解压位置**: 建议解压到有读写权限的目录（如桌面、文档文件夹）
2. **首次运行**: 便携版首次运行时可能需要较长时间来初始化
3. **防火墙**: 某些防火墙可能会阻止便携版程序，请添加信任
4. **数据备份**: 建议定期备份 `data/` 目录中的数据文件
5. **完整解压**: 确保解压时保持目录结构完整

## 🆚 便携版 vs 安装版

| 特性     | 便携版            | 安装版                 |
| -------- | ----------------- | ---------------------- |
| 安装过程 | 解压即用          | 需要安装               |
| 系统集成 | 无                | 开始菜单、桌面快捷方式 |
| 自动更新 | 支持              | 支持                   |
| 数据位置 | 程序目录          | 用户数据目录           |
| 卸载     | 删除文件夹        | 控制面板卸载           |
| 文件格式 | ZIP压缩包         | EXE安装程序            |
| 适用场景 | 临时使用、U盘携带 | 长期使用、系统集成     |

## 💾 数据迁移

### 从安装版迁移到便携版

1. 找到安装版的数据目录（通常在 `%APPDATA%/qnote`）
2. 将数据文件复制到便携版的 `data` 目录中

### 在不同设备间迁移

1. 复制整个便携版文件夹到新设备
2. 确保新设备有运行权限
3. 直接运行即可

## 🔧 故障排除

- **无法运行**: 检查是否被杀毒软件拦截
- **权限错误**: 右键选择"以管理员身份运行"
- **缺少依赖**: 安装 Visual C++ Redistributable
- **解压失败**: 使用支持长路径的解压工具
