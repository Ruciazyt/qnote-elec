**P0-3　隐藏控件仍在焦点序（8 处硬伤 + 2 处附记）**

> 口径：**可聚焦元素自身或它的祖先被隐藏、且没有「焦点时显形」的规则**，
> 才算硬伤。纯装饰的透明图标不算。

- `src/renderer/components/Leetcode/SideBar.tsx` —— 题单卡片的编辑/删除操作区
  （`opacity-0 group-hover:opacity-100` + `pointer-events-none`）
  改法：`focus-within:opacity-100` + `focus-within:pointer-events-auto`
  （容器挡住了指针，键盘聚焦后也要能点）
- `src/renderer/pages/BrowserPage.tsx` —— 标签页的关闭按钮
  （`opacity-0 group-hover:opacity-70`）
  改法：`focus-within:opacity-70`
- `src/renderer/components/apps/AppProjectHeader.tsx` —— 复制地址按钮
  （`opacity-0 group-hover:opacity-100`）
  改法：`focus-within:opacity-100`
- `src/renderer/components/sticky/StickyNoteApp.tsx` —— 便签右上角的删除按钮
  （`opacity-0 group-hover:opacity-100`）
  改法：`focus-within:opacity-100`
- `src/renderer/pages/SkillsPage.tsx` —— 技能卡片操作区（编辑技能 / 删除技能）
  （`opacity-0 group-hover:opacity-100`）
  改法：`focus-within:opacity-100`
- `src/renderer/components/todo/TodoEditDialog.tsx` —— 附件角上的「移除附件」按钮
  （`opacity-0 group-hover/att:opacity-100`）
  改法：容器加 `focus-within:opacity-100`
- `src/renderer/components/browser/BookmarkList.tsx` —— 打开收藏 / 删除收藏两颗按钮
  （`text-muted-foreground/0`，完全透明）
  改法：加 `focus-visible:text-muted-foreground/70`
  （这两颗不是 `opacity-0`，别照抄 opacity 写法）

**这 8 处全是「悬停才显形的行内操作」，统一用 `focus-within` / `focus-visible` 显形。**
结构性隐藏（整块收起）另用 `visibility: hidden` 或 `inert` ——
整块收起时套 `focus-within` 会让折叠区在 Tab 进来时突然显形。

附记 2 处（非可聚焦元素，不构成焦点序问题，但别忘了）：

- `src/renderer/components/sticky/StickyNoteApp.tsx` —— 便签缩放手柄
  （不可聚焦，但它缺 `role` / `tabIndex`，见 P1-8）

不算硬伤（别去改）：`CollectionDetail.tsx` 的两枚 Edit2 图标（在可见按钮内部）、
`settings.tsx` 的「已保存」提示 span（`pointer-events-none` + `aria-live`）、
`ui/toast.tsx` 的关闭按钮（已带 `focus:opacity-100`）、
`ui/sidebar.tsx`（shadcn 内置件）。

- 违反：第五节「看不见的控件必须移出焦点序」。这些地方只写了

  Tab 照样能进去，进去时控件与焦点框都是不可见的。
- 怎么测：窗口显示后 `win.focus()` 再发 Tab，循环到 `activeElement.id` 命中为止，
  数落点里有没有 `opacity-0` / `text-foreground/0` 的可聚焦元素。

## 四、测量方法

### 对比度口径（唯一一套算法，2026-11-05 定案）

此前三个人各算各的，同一个组合能给出 1.16 / 1.76 / 2.41 / 2.74 四种值。
现在定死一套：

1. **WCAG 2.x 相对亮度公式**（sRGB → 线性 → 相对亮度 → 比值）。
2. **sRGB 线性化阈值取 0.03928 与 0.055**：`v ≤ 0.03928` 走线性段
   （`v / 12.92`），否则 `(v + 0.055) / 1.055` 再取 2.4 次方。
3. **HSL 按 CSS 规范转 sRGB**，转换后**保留浮点，不取整到 8-bit** ——
   取整会让临界比值漂 0.01~0.02（例如 `primary` 白底会算成 4.95 而不是 4.93）。
4. **透明档先做 alpha 合成再算**：`bg-primary/10` 要先把 primary 与底色按
   10% 合成出实际颜色，再拿它当底色；`text-muted-foreground/70` 同理
   （先把文字色与底色合成，再与底色比）。
5. **底色只有两种**：`--card`（100% 白）与 `--background`（98%）；
   暗色主题同理（`--card` / `--background`）。**结论取更差的那个。**
6. **复现**：`scripts/check-contrast.mjs`（Node、无依赖）输出每个组合对两个底
   各一行。**文档里的数从它的输出抄** —— 改了 token 先重跑脚本，再回来改文档。

### 焦点态

`:focus-visible` 只在「窗口已显示且已获焦」时成立 ——
隐藏窗口（`show:false`）里无论怎么 `win.focus()` 都不成立，量到的会是
`box-shadow: none`，很容易被误读成「样式没生效」。要用真实键盘事件
（`sendInputEvent` 发 Tab），而且 Tab 的落点是有记忆的，要循环 Tab 到
`activeElement.id` 命中为止。

### 几何

折叠轨的几何已经被 `panel/layout.test.ts` 的等式断言锁死
（轨宽 = 内缩 × 2 + 按钮边长，内缩 = 展开态头部左内边距），
改了几何先跑那条测试，不用重新量 DOM。
